#  MediFinder – Medicine Availability Checker

MediFinder is a web-based application that helps users quickly find and check the availability of medicines across different medical stores. The platform reduces the time and effort required to search for medicines by providing real-time availability information, store details, and contact information in a single place.

##  Features

*  Search medicines by name
*  View available medical stores
*  Check medicine availability status
*  Access pharmacy contact details
*  Secure admin login system
*  Add and manage medicine inventory
*  Responsive and user-friendly interface

##  Tech Stack

### Frontend

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

### Backend

* Flask (Python)

### Database

* SQLite

## Problem Statement

Finding medicines during emergencies can be challenging, as users often need to visit multiple pharmacies to check availability. MediFinder simplifies this process by providing a centralized platform where users can instantly search for medicines and locate nearby stores that have them in stock.

##  Key Objectives

* Reduce the time spent searching for medicines
* Improve accessibility to medicine availability information
* Provide an easy-to-use platform for patients and senior citizens
* Enable pharmacies to manage and display their inventory efficiently

##  Future Enhancements

*  Location-based pharmacy search
*  Online medicine ordering
*  User registration and profiles
